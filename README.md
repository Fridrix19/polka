# Polka

Оплата зарубежных сервисов рублями: долларовая виртуальная карта и каталог из 113 сервисов, оплата по QR через СБП.

Бренд — «журнал о подписках»: бумага `#F2EDE3`, чернила `#1A1712`, вермильон `#D8431C`, охра `#E3B23C`; шрифты Playfair Display (заголовки, курсив — акценты), Golos Text (текст), JetBrains Mono (цифры). Прямые углы, линейки вместо карточек, шапка-«заголовок журнала» с датой выпуска. Знак — книги на полке (`build/brand/logo.svg`), иллюстрация — `build/brand/hero-art.svg`. Дневной выпуск по умолчанию, ночной — переключателем в подвале и в мобильном меню.

У каждой страницы свой первый экран: обложка с оглавлением «В этом номере» (главная), указатель разделов (каталог), «интервью» (вопросы), четыре кадра (как устроено), бюро помощи (поддержка), редакция (контакты), прайс-лист (тарифы), характеристики карты (карта), рубрика (раздел), шапка издания (сервис). Кабинет — содержание справа, админка — «редакция» с оглавлением справа.

## Структура

```
_proto/          собранный сайт (статика): главная, каталог, разделы, 113 страниц сервисов, карта, как это устроено,
                 помощь, контакты, вопросы, тарифы, вход, личный кабинет
src/base/        общая база: токены и компоненты (base.css, lib.css), шапка, подвал и мобильное меню, common.js
src/pages/       страницы: <page>.html|js|css, данные разделов section-<id>.json
build/           сборка build.py, бренд brand/, icon-lum.json (яркость логотипов сервисов)
source-site/     данные каталога: логотипы сервисов (assets/), список (search.js), тарифы (payment-flow.v2.js)
web/             бэкенд и админка: Nuxt 4 + Nitro, PostgreSQL — см. web/README.md
render.yaml      стенд на Render + Neon
```

## Сборка

```bash
python3 build/build.py            # все страницы, кроме сервисов
python3 build/build.py all        # всё, включая 113 страниц сервисов
cd web && npm ci && npm run build # сервер отдаёт _proto/ и API /api/*
```

## Отдельный стенд

У Polka своя база, свои админы и пользователи. Для стенда: новый проект в Neon, новый Web Service в Render из этого репозитория (настройки — в `render.yaml`), свои значения `NUXT_DATABASE_URL`, `NUXT_SECRET`, почты и `NUXT_PUBLIC_SITE_URL`. Первый вход в админку `/admin` — admin / admin, затем смена пароля.

## Запуск на своём компьютере (Mac)

Нужны Node.js 20+ и [Postgres.app](https://postgresapp.com) (Initialize → Start). Затем:

```
cd web && bash start-local.sh
```

Скрипт сам создаст базу `polka`, поставит зависимости, соберёт проект, применит миграции и запустит сервер: сайт — http://localhost:3001, админка — http://localhost:3001/admin (admin / admin, затем смена пароля). Код регистрации показывается на экране, письма — в логе.

## Бета на Vercel

Репозиторий готов к выкладке на Vercel как бета-стенд: сайт, кабинет и админка в одном проекте, база — Neon (PostgreSQL).

1. vercel.com → Add New → Project → импорт `Fridrix19/polka`. Настройки сборки менять не нужно — они в `vercel.json`.
2. В проекте: Storage → Create Database → Neon, регион Frankfurt (eu-central-1) → подключить к проекту. Переменные `DATABASE_URL` и `DATABASE_URL_UNPOOLED` появятся сами.
3. Deployments → Redeploy. При сборке накатываются миграции и создаются тестовые входы.

Входы на бете:
- кабинет: `test@gmail.com` / `test` (подсказка есть на странице входа);
- админка: `/admin`, `admin` / `admin`, смена пароля на бете отключена.

Что работает иначе, чем на своём сервере:
- файлы загружаются до 4 МБ за раз (лимит Vercel), фото сжимаются в браузере автоматически;
- курс ЦБ (если включён автокурс) обновляется раз в сутки по расписанию Vercel;
- коды подтверждения почты показываются на экране — настоящие письма не уходят.

Необязательно: `NUXT_SECRET` (иначе ключ берётся из адреса базы) и `CRON_SECRET` (защита расписания).
Хранить данные реальных клиентов на бете нельзя: Vercel и Neon за рубежом, а по 152-ФЗ персональные данные россиян хранятся в России.
